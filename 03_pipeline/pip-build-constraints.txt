# SECOND LINE OF DEFENCE, not the primary fix.
#
# Exported as PIP_CONSTRAINT by 03_pipeline/create_env.sh. Some pip versions
# apply constraints when populating an ISOLATED PEP 517 build environment;
# others do not. On the cluster (2026-08-24) it did NOT prevent the failure, so
# do not rely on it.
#
# THE PRIMARY FIX IS IN environment.yml: `setuptools<81` and `wheel` as conda
# dependencies. With `wheel` present pip takes the legacy setup.py build path,
# which runs in the TARGET env and therefore uses the bounded setuptools.
# Without it pip uses PEP 517 with an isolated env that installs
# `setuptools>=40.8.0` unbounded -- i.e. 84.0.0, which removed pkg_resources,
# which pybedtools 0.9.1's setup.py imports.
#
# Measured on pybedtools 0.9.1 with setuptools 80.9.0 in the env:
#   no wheel, isolation ON   -> FAILED   (the cluster failure)
#   no wheel, isolation OFF  -> BUILT
#   wheel present, ON        -> BUILT
#   wheel present, OFF       -> BUILT
setuptools<81
